This folder contains shareable / viewable copies of the documentation for the Custom Braille Embosser (`.pdf`, `.csv`). The [`Working_Documents/`](Working_Documents) subfolder contains the editable source versions (`.docx`, `.xlsx`). The [`_drafts/`](_drafts) subfolder contains fully-written markdown drafts of every required document; their content can be pasted into the matching `.docx` files in `Working_Documents/` and exported to PDF.

When the design is updated, regenerate the PDFs from the working documents and replace the older PDFs in this folder. Filenames must remain stable so existing links keep working (e.g. `Custom_Braille_Embosser_Maker_Guide.pdf`).

## Documents
| Document             | Format(s)                  |
|----------------------|----------------------------|
| Bill of Materials    | `.csv` (here) + `.xlsx` (in `Working_Documents/`) |
| Design Rationale     | `.pdf` (here, after export) + `.docx` (in `Working_Documents/`) + `.md` (in `_drafts/`) |
| Maker Guide          | `.pdf` + `.docx` + `.md`   |
| User Guide           | `.pdf` + `.docx` + `.md`   |
| Quickstart Guide     | `.pdf` + `.docx` + `.md`   |
| Summary              | `.pdf` + `.docx` + `.md`   |
