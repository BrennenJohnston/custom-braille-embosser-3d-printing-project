This folder contains the design files for the Custom Braille Embosser. The device has no PCB; only `CAD_Design_Files` are required.

## Subfolders
- [`CAD_Design_Files/Fusion/`](CAD_Design_Files/Fusion) - native Autodesk Fusion 360 archive (`.f3z`) of the full assembly. Open this if you want to make parametric edits in Fusion 360.
- [`CAD_Design_Files/STEP/`](CAD_Design_Files/STEP) - neutral STEP exports of the full assembly and each sub-assembly (Body, Cylinder Roller Holder, Grip Extension, Handle Connector + Handle Grip). Use these if you are editing the design in CAD packages other than Fusion 360.
- [`CAD_Design_Files/OBJ/`](CAD_Design_Files/OBJ) - per-part `.obj` exports with matching `.mtl` material files for visualisation, rendering, and on-line viewing.
